STEP BY STEP · 2 MINUTES

Setup Guide

Get the farm running in under two minutes. Follow the steps below exactly.

1

Open Roblox and join BABFT

Launch Roblox and search for Build a Boat for Treasure. Join any server and wait until you're fully loaded into the game and can see your boat.

2

Open your executor

Launch your script executor (Synapse X, KRNL, Fluxus, Arceus X, Delta, etc.) and attach it to Roblox. Wait for the "Attached" or "Injected" confirmation before continuing.

3

Copy the script

Go to the Script page and click the COPY SCRIPT button. The full loader script will be copied to your clipboard automatically.

4

Paste into your executor

Click inside your executor's script input box and paste the script (Ctrl+V on PC, long-press → Paste on mobile). Make sure the full script is there.

5

Execute the script

Press the Execute button in your executor. The script will fetch the latest farm build from the remote server and start running immediately.

6

Watch the farm run

The auto farm is now active. You can minimize Roblox and leave it running. Gold and treasures will be collected automatically in an infinite loop until you close the game or stop the executor.

Tips for best results

💡 Use a private server

Running the farm on a private server reduces lag and ensures the farm loop isn't disrupted by other players.

💡 Lower graphics settings

Set Roblox graphics to level 1 before starting the farm. It reduces CPU/GPU load significantly during long AFK sessions.

💡 Plug in while farming

If you're on a laptop, keep it plugged in. Long sessions can drain the battery faster than the charger replenishes it.

💡 Re-execute after crashes

If Roblox crashes or disconnects, simply rejoin and run the script again. The loader always fetches fresh — no changes needed.

Troubleshooting

!

Script doesn't execute

Make sure your executor is fully attached to Roblox before running. Try detaching and re-attaching, then execute again.

!

"HttpGet not found" error

Some free executors disable HttpGet. Switch to KRNL, Fluxus, or any executor that supports HTTP requests. Synapse X always works.

!

Farm stops after a few minutes

This can happen after a game update. The script auto-updates on each run, so simply re-execute and it should work again immediately.
