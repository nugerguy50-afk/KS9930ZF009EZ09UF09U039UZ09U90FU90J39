How the loader works

The script uses a character-code array to build a URL at runtime — a technique that keeps the destination out of plain text. When executed, it fetches the actual farm script via HttpGet and runs it with loadstring. The core logic is hosted remotely and always up-to-date without you needing to touch anything.

🔍WHAT THE LOADER BUILDS

The char array decodes to a GitHub.io URL that hosts the main farm logic. GitHub Pages is a static file host — no server-side code runs there, nothing is logged or collected. You can verify this yourself: open your browser's DevTools → Network tab → run the script and watch what URL it fetches.

STEP BY STEP · 2 MINUTES

Setup Guide

Get the farm running in under two minutes. Follow these steps in order.

1

Open Roblox and join BABFT

Launch Roblox and search for Build a Boat for Treasure. Join any server and wait until you're fully loaded into the game.

2

Open your executor

Launch your script executor and attach it to Roblox. Wait for the "Attached" or "Injected" confirmation before moving on.

3

Copy the script

Go to the Script page and click COPY SCRIPT. The loader copies to your clipboard and the global counter increments by one — live for everyone.

4

Paste into your executor

Click inside the executor's script box and paste — Ctrl+V on PC, long-press → Paste on mobile. Confirm the full script is there before proceeding.

5

Execute the script

Press Execute in your executor. The loader fetches the latest farm build from the remote server and starts immediately.

6

Let it run

The farm is now active. Minimize Roblox if you like — gold and treasures are collected automatically in an infinite loop until you close the game.

Pro tips

💡 Use a private server

Reduces lag and means the farm loop isn't disrupted by other players building or joining mid-run.

💡 Lower graphics to Level 1

Significantly reduces CPU and GPU load — essential for long AFK sessions that run overnight.

💡 Stay plugged in

On a laptop, keep it plugged in. Hours of farming can drain battery faster than a charger keeps up.

💡 Re-execute after crashes

If Roblox disconnects, rejoin and run the script again. The loader always fetches fresh — no changes needed.

Troubleshooting

!

Script doesn't execute

Make sure your executor is fully attached to Roblox first. Try detaching and re-attaching, then execute again.

!

"HttpGet not found" error

Some free executors disable HttpGet. Switch to KRNL, Fluxus, or any executor that supports HTTP requests.

!

Farm stops mid-session

Usually caused by a game update. Re-execute — the script auto-fetches the latest patched build every run.
